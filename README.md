# 🌉 놀이다리

> **발달지원센터를 기다리는 영유아 부모가 집에서 AI 맞춤 놀이를 실천하고 기록하면서, 대기기간의 지원 공백을 줄이고 센터 상담까지 이어갈 수 있도록 돕는 플랫폼**

'놀이다리'의 '다리'는 두 가지 연결을 뜻합니다. **센터를 기다리는 기간과 전문 지원이 시작되는 시점**을 잇고, **부모와 아이를 놀이로** 잇습니다.

> ⚠️ 놀이다리는 의료 서비스가 아니며 발달지연이나 발달장애를 진단하지 않습니다. 놀이 추천은 전문 평가와 치료를 대신하지 않습니다. 걱정되는 징후가 있으면 전문기관 상담을 안내합니다. 아동 정보와 사진은 보호자 동의를 받은 경우에만 수집·보관하며, 보호자가 언제든 삭제할 수 있습니다.

📄 전체 기획: [서비스 기획서](docs/service-plan.md) · [시연 시나리오](docs/demo-scenario.md) · [기획 남은 일](docs/planning-todo.md) · [기능 개선 아이디어](docs/feature-ideas.md) (기획 담당)

## 왜 필요한가
```
센터 대기 → 가정 내 발달 지원의 어려움 → 부모의 경제적·심리적 부담 증가
```
1. **대기기간의 지원 공백**: 차례가 올 때까지 집에서 무엇을 해야 할지 모르고, 아이 변화를 기록할 방법도 없음
2. **경제적 부담**: 무료·저비용 활동 정보는 흩어져 있고, 교구나 프로그램을 따로 알아봐야 한다는 압박이 있음
3. **심리적 부담**: 믿을 만한 놀이 정보가 부족하고, 비슷한 처지의 부모와 이야기할 곳이 없음

## 사용자
**만 0~6세 영유아의 부모·보호자** 가운데 발달지연이 걱정되거나 전문기관 이용을 기다리는 사람. 대부분 전문 지식이 없으므로 **전문 용어 없이 따라가기만 하면 되는 화면**을 목표로 합니다.

## 이용 흐름
```
① 가입·아이 정보 → ② 발달 상태 확인 설문 → ③ AI 맞춤 놀이 추천 → ④ 놀이
        → ⑤ 사진·메모 기록 → ⑥ 기록을 반영한 다음 추천 → ⑦ 센터 전문가와 기록 공유
                 └──────── ③ → ④ → ⑤ → ⑥ 반복 (핵심) ────────┘
```

## 기능
### 1. 발달 상태 확인 설문
- **영아용(0~35개월) / 유아용(36~83개월)** 각 9문항 = 발달 5문항 + 기질 4문항. 유아도 "더 쉬운 질문(영아용)"으로 바꿀 수 있음
- 발달 문항(**언어·인지·사회성·대근육·소근육**): "할 수 있나요?" 대신 **지금 모습에 가장 가까운 단계 ①②③ / 아직이에요**를 고름 → 고른 단계가 놀이 시작 단계
- 기질 문항(탐색·신중·주도·회복): **자주 그래요 / 가끔 그래요 / 거의 아니에요** → '우리 아이 놀이 스타일'(탐색형·신중형·주도형)로 놀이 진행 팁만 바꿈
- 결과를 영역별로 정리해서 보여줌
- "진단이 아니라 놀이 추천을 위한 참고"라는 안내를 표시하고, 주의가 필요한 응답이 있으면 **전문기관 상담 권유**

### 2. AI 맞춤 놀이 추천
- 월령, 영역별 결과, 지원이 더 필요해 보이는 영역을 함께 고려
- 놀이 카드: **목표 영역 · 준비물 · 진행 순서 · 소요 시간 · 아이가 어려워할 때 대처 팁**
- 집에 있는 물건 위주, 10~20분 안에 끝나는 활동
- 치료나 훈련이 아닌 **부모와 아이가 함께 즐기는 놀이 가이드**

### 3. 놀이 기록 · 추천 고도화 (핵심 차별점)
1. **기록**: 수행 여부(완료 / 일부 진행 / 못함) + 반응(즐거워함 / 보통 / 어려워함) + 메모 + 사진
2. **분석**: 흥미를 보인 놀이 유형과 어려워한 활동을 정리
3. **추천 개선**: 즐거워한 놀이 → **한 단계 위**, 어려워한 놀이 → **쉬운 단계나 다른 방식**, 한 영역에 몰리지 않게 **균형 유지**
4. **조회·공유**: 날짜별·영역별 기록 조회. 센터 방문 전 **기간별 요약 리포트**를 만들어 보호자가 원할 때 전문가에게 공유
- AI는 **사진으로 발달 수준을 판단하지 않음**. 기록 분석은 다음 놀이를 고르기 위한 참고일 뿐, 해석과 평가는 전문가의 몫

### 4. 부모 커뮤니티
- 게시판: **놀이 후기·아이디어 / 센터 이용·준비 경험 / 고민 나누기**
- 놀이 카드에서 바로 후기 작성 → 다른 부모가 놀이를 고를 때 참고
- 안전 운영: 닉네임으로 활동, 실명·기관명 쓰지 않도록 안내, 아이 얼굴 사진 주의 안내와 흐림 처리, 효과를 단정하는 글에 '검증되지 않은 정보' 표시, 신고와 관리자 검토

## AI와 개인정보
아이 정보를 다루므로 **외부 AI API로 데이터를 보내지 않습니다.**
- **추천·단계 조정·영역 균형**: 규칙으로 계산 (설문 점수 + 기록 반응 + 놀이 단계)
- **메모 분석·리포트 문장**: 로컬 AI (Ollama + `qwen2.5:7b`, 내 컴퓨터 안에서만 동작). 로컬 AI가 꺼져 있으면 규칙으로 만든 기본 문장을 사용
- 놀이는 `data/plays.json`에 있는 것만 추천 (AI가 놀이를 새로 지어내지 않음)

## 기술
Next.js (App Router, TypeScript, Tailwind) · Supabase (인증·DB·사진 저장) · Ollama (로컬 AI)

```bash
npm install
cp .env.example .env.local   # Supabase 키 입력
npm run dev                  # http://localhost:3000

# 로컬 AI (선택)
ollama pull qwen2.5:7b
```

## 구조
```
src/app/              화면
src/types.ts          팀 공통 타입              ← 계약
```

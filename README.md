# 🌱 하루놀이

**센터에서 집까지, 하루 10분 놀이.**
발달센터 치료를 기다리는 만 3~5세 아이의 부모에게, 아이 수준에 맞는 놀이를 추천하고 센터 치료사가 확인해 보내주는 센터 연계형 서비스입니다.

> ⚠️ 선별·놀이 참고용이며 진단·치료를 대체하지 않습니다. 기록 공유는 부모 동의 후에만 이루어집니다.

## 왜 필요한가
- 발달센터 치료 시작까지 3개월 이상 대기 → 그 사이 집에서 할 일 안내가 없음
- 월 치료비 최대 180만원, 대부분 건강보험 비급여 (전국장애인부모신문, 2026.10.26)
- 부모 설문(n=52)에서 가장 불편했던 점: "우리 아이에게 맞는 놀이를 고르기 어렵다" 33%, "놀이 방법과 순서를 모르겠다" 27%

## 흐름
```
① 입력            ② 놀이 추천        ③ 센터 확인          ④ 가정 실천·기록
9문항 체크·       →  규칙 기반으로   →  치료사가 검토    →  해봤어요/어려웠어요/
걱정 영역·          놀이 카드 생성      후 부모에게 발송     반응 좋았어요 + 메모·사진
좋아하는 놀이                                               → 다음 추천에 반영
```

## MVP 기능
| 화면 | 내용 |
|---|---|
| 로그인 | 센터가 발급한 계정으로 로그인, 부모/센터 역할 구분 |
| 간편 체크 (부모) | 아이 애칭·생년월일·성별, 좋아하는 놀이(8개 영역), 걱정되는 누리과정 영역, 발달 5문항 + 기질 4문항(3단계), 센터 공유 동의 |
| 놀이 카드 (부모) | 놀이 순서(분 단위)·재료·발달 포인트·발문 예시·다음 단계·누리과정 연계·기질 맞춤 팁 |
| 기록 (부모) | 반응 3단계 + 메모 + 사진 → 센터로 보내기 |
| 센터 화면 | 아이 목록, 추천 카드 확인·수정·발송, 가정 기록 확인 |
| 센터·보호자 대화 | 아이별 메시지 |

나중에: 부모 커뮤니티, 성장 그래프, 결제(부모 월 구독 / 센터 구독)

## 추천 방식
LLM API 없이 **규칙 기반**으로 동작합니다 (팀원 프로토타입 로직과 동일).
1. 발달 5문항(대근육·소근육·언어·인지·사회성) 중 점수가 가장 낮은 영역 → 해당 영역 놀이
2. 기질 4문항 → 탐색형 / 신중형 / 주도형 → 기질 맞춤 팁
3. 놀이는 `data/plays.json`에 있는 것만 추천 (감수 전 놀이는 추천 금지)

LLM은 추후 선택 기능(설명 문구, 기록 요약)으로만 검토합니다. 사용할 서비스는 미정입니다.

## 기술
Next.js (App Router, TypeScript, Tailwind) · Supabase (인증·DB·사진 저장)

```bash
npm install
cp .env.example .env.local   # Supabase 키 입력
npm run dev                  # http://localhost:3000
```

## 구조
```
src/app/            화면
src/types.ts        팀 공통 타입        ← 계약
data/plays.json     놀이 라이브러리      ← 계약
supabase/schema.sql DB 스키마·접근 권한  ← 계약
```
계약 파일 3개를 바꿀 때는 PR을 올리고 팀원 전원의 확인을 받습니다.

## 협업 규칙
- `main`에 직접 push 금지: 브랜치를 만들어 PR을 올리고 1명 이상 승인 후 merge
- 브랜치 이름: `feat/이슈번호-내용`, `fix/이슈번호-내용` (예: `feat/3-check-form`)

- API 키는 `.env.local`에만 저장 (커밋 금지)
- AI 도구(Claude 등)를 써도 커밋·PR에 AI 기여자 표기(`Co-Authored-By: Claude ...`, "Generated with Claude Code" 등)를 넣지 않음
